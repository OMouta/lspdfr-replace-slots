Standard Replace File Pattern

For most replace installs, rename the files to match the model slot:

modelname.yft
modelname_hi.yft
modelname.ytd
modelname+hi.ytd

Example:

polcaracara.yft
polcaracara_hi.yft
polcaracara.ytd
polcaracara+hi.ytd
